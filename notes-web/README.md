# 拾记移动端 Web 前端

基于已确认的移动端原型实现的 React 前端。采用“原生轻量”设计：首页以简洁文件夹列表聚合展示，数量放在右侧，子文件夹名称作为辅助信息。笔记列表包含摘要和图片缩略图，编辑页使用白底文稿与轻量格式工具栏。右上角进入空间设置，没有导航 Tab。浅色、深色共用同一套字体层级、间距和组件规范。

## 启动

```sh
npm install
npm run dev
```

访问 http://127.0.0.1:5173 。生产构建执行 `npm run build`，生成 dist；可以使用 `npm run preview` 查看构建结果。

## 服务端接入（2026-10-03）

现在使用 ../notes-server-go 提供的真实 API。先按服务端 README 启动 API、迁移数据库和创建首次管理员邀请，再启动网页。Vite 将 /api 代理到 127.0.0.1:8000；首次用户打开邀请链接自行设置密码。

- Cookie 登录、用户独立空间、服务端文件夹与笔记存储。
- Tiptap JSON 正文、最多 10 MiB 图片上传、私有附件读取。
- 串行自动保存、版本冲突提示、按用户/笔记/编辑器隔离的草稿恢复。
- 真实 Token 权限和撤销；完整密钥仅创建时显示一次。标签权限加入新模板，回收站权限可选。
- 编辑页标签选择、移除和创建；标签修改同样保存到服务端并支持草稿恢复。
- 创建笔记使用幂等键，短暂网络/服务故障重试保持相同请求；Agent 的 Markdown/按块写入可在 Web 读取。
- 更多操作 → 历史版本：只读预览、确认恢复，冲突时显式刷新当前版本再决定。恢复后可以立即继续编辑。
- 空间设置 → 导出图文包：笔记与图片 ZIP，可选历史和回收站，浏览器原生下载；15分钟内可以再次下载。解压后 index.html 可离线阅读当前图文，历史版本为 JSON。

旧原型 localStorage 保留，不会自动导入登录账号。正式 Skill 位于 ../notes-skill/shiji-notes。历史与导出已接入；导入和生产部署验收尚待后续阶段。历史默认每篇保留最近200个版本，旧笔记从升级时开始记录。

## 原型阶段记录（已被服务端接入替代）

- 这是已实现的前端界面，尚未连接后端、真实用户认证或远程 API。
- 文件夹与笔记通过 localStorage 保存在当前浏览器；清除浏览器数据会清除这些记录。空间设置可以导出 JSON 数据副本。
- Token 页面为明确标注的界面演示，生成的值不具有实际权限，不存储真实凭证。
- 图文编辑支持标题、段落、加粗、斜体、列表、引用、代码、图片、撤销和重做。本地演示图片上限为 2 MB；实际服务附件上限、权限和配额由未来后端处理。
- 资源图为随前端提供的示例路线草图。

## 文件职责

- src/styles.css：主题、组件状态和手机断点。
- src/FolderBrowser.tsx：文件夹聚合、服务端搜索结果、摘要/标签/图片预览。
- src/NoteEditor.tsx、NoteTags.tsx：图文与标签编辑。
- src/HistoryPanel.tsx、editorExtensions.ts：历史列表、恢复和共享图文节点。
- src/Settings.tsx：账户、真实 Token 与导出入口。
- src/api.ts、useRemoteLibrary.ts：API 映射、服务端工作区与草稿协调。
- src/saveQueue.ts、draftStore.ts：串行版本保存、多编辑器草稿隔离。
- src/App.tsx：认证、页面状态、冲突反馈、文件夹创建。
- src/data.ts：数据类型及保留的原型示例数据。

浏览器恢复草稿不等同于服务端备份；完整备份需要数据库和附件目录。
